# 一、文本创作与 AI 助手

## 1. ChatGPT

ChatGPT 是目前应用范围非常广泛的 AI 助手之一，可以用于写作、翻译、代码、数据分析、头脑风暴以及日常问答等场景。

**适合场景：**

- 文案和文章创作
- 代码编写与调试
- 文件分析
- 数据整理
- 翻译与润色
- 学习辅助
- 创意 brainstorming
- 日常效率提升

**使用建议：**

不要只把 AI 当成“搜索框”。

如果希望得到更加稳定的结果，可以在提问时明确：

> 角色 + 背景 + 任务 + 输出格式 + 限制条件

例如：

```text
你是一名 SEO 内容编辑。

背景：
我正在制作一篇面向中文用户的 AI 工具介绍文章。

任务：
帮我整理 10 个适合普通用户的 AI 工具。

要求：
1. 使用简体中文
2. 不要夸张宣传
3. 每个工具说明主要功能、适用人群和优缺点
4. 使用 Markdown 表格输出
```

# 六、Prompt 提示词入门与进阶

很多用户使用 AI 时遇到的问题，并不是 AI 本身能力不足，而是输入的信息不够明确。

一个比较实用的 Prompt 可以包含：

### 1. Role｜角色

告诉 AI 当前应该以什么身份工作。

例如：

```text
你是一名拥有多年经验的 SEO 内容编辑。
```

### 2. Context｜背景

告诉 AI 当前任务的背景。

```text
我正在制作一个面向中文用户的 AI 工具导航网站。
```

### 3. Task｜任务

明确告诉 AI 要完成什么。

```text
请帮我整理 20 个适合普通用户使用的 AI 工具。
```

### 4. Output｜输出格式

告诉 AI 最终结果应该如何呈现。

```text
请使用 Markdown 表格。
```

### 5. Constraints｜限制条件

告诉 AI 哪些内容不要出现。

```text
不要使用夸张宣传，不要虚构数据。
```

# 八、AI 常见问题 FAQ

## Q1：为什么某些 AI 网站打不开？

可能原因包括：

- 当前网络连接存在限制
- DNS 解析异常
- IP 地区与服务要求不匹配
- 浏览器缓存或 Cookie 问题
- 服务商临时故障
- 当前账号或地区暂不支持相关功能

可以按照下面的顺序进行排查：

**网络 → DNS → IP → 浏览器 → 账号 → 服务状态**

---

## Q2：如何查看自己的公网 IP？

可以使用 IP 信息查询服务查看当前公网出口地址、地区、ASN 等基础信息。

例如：

**IPInfo**

可用于查看当前 IP 的基础信息、网络运营商以及大致地理位置。

同时建议注意：

> IP 地理位置查询通常只是近似结果，不代表实际物理位置。

# 十一、IP 与网络环境检测

当 AI 网站出现访问异常、登录异常或者功能不可用时，可以先检查当前网络环境。

建议按照以下顺序检查：

### ① 查看公网 IP

使用 IP 查询工具确认当前公网出口地址。

### ② 查看 IP 地区

检查查询结果中的：

- Country
- Region
- City
- ASN
- Organization

### ③ 查看网络运营商

部分服务会根据 ASN、IP 类型以及网络环境进行不同的访问处理。

### ④ 检查 DNS

如果出现网页打不开、域名解析异常等问题，可以进一步检查 DNS。

### ⑤ 检查浏览器

可以尝试：

- 无痕窗口
- 清除 Cookie
- 清除缓存
- 更换浏览器

# 十二、网络连接问题排查

如果 AI 工具访问异常，可以按照以下流程逐步排查：

```text
                    AI 网站无法访问
                           │
                           ▼
                     检查网络连接
                           │
                           ▼
                       检查公网 IP
                           │
                           ▼
                     检查 IP 地区
                           │
                           ▼
                       检查 DNS
                           │
                           ▼
                    检查浏览器缓存
                           │
                           ▼
                    检查客户端配置
                           │
                           ▼
                    检查服务商状态
```

不要一遇到问题就直接更换大量设置。

逐项排查通常更容易找到真正原因。
