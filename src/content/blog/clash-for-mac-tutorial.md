得益于 macOS 优雅的系统环境与权限管理，在 Mac 上配置代理工具通常比其他平台更加省心。目前在 macOS 上主流的选择有经典开源的 **ClashX** 以及跨平台的新星 **Clash Verge (Rev)**。

## 客户端选择建议

- **ClashX / ClashX Pro**：常年霸榜的经典 Mac 专属客户端。小巧轻量，直接驻留在顶部菜单栏，非常契合原生 Mac 交互习惯。
- **Clash Verge**：拥有现代化的主界面面板，跨平台统一体验，支持更多新型协议。如果您习惯在可视化面板里管理节点，推荐使用。

本教程以经典的 **ClashX** 为例进行讲解。

## 第一步：下载与授权

1. 访问 GitHub 获取 ClashX 的最新 `.dmg` 安装包。如果您的 Mac 是 M1/M2/M3 等 Apple Silicon 芯片，下载页面通常无需区分版本，直接下载统一安装包即可。
2. 双击打开 `.dmg` 文件，将小猫咪图标拖拽至旁边的 `Applications (应用程序)` 文件夹中。
3. 从启动台中打开 ClashX。首次运行时，系统可能会弹出“这是一个从互联网下载的App...”的安全提示，点击 **打开**。
4. **核心步骤**：ClashX 首次启动需要安装 Helper 工具以接管系统代理，此时会弹出密码输入框，请**输入您的 Mac 开机密码或使用触控 ID** 授权安装。

## 第二步：导入节点订阅

当在顶部状态栏看到黑色的小猫咪图标后，即可开始配置：

1. 前往您的服务商网站，复制专属的 **Clash 订阅链接**。
2. 点击顶部状态栏的 ClashX 小猫咪图标。
3. 在下拉菜单中选择 **配置 (Config)** -> **托管配置 (Remote Config)** -> **管理 (Manage)**。
4. 在弹出的窗口中点击右下角的 **添加 (Add)**。
5. 在 `Url` 栏中粘贴您刚刚复制的订阅链接，`Name` 栏可以随意填写（如“我的节点”），然后点击确定。
6. 等待数秒钟，配置会自动下载。下载完成后，关闭该窗口。

## 第三步：开启系统代理

配置导入成功后，所有的节点列表会自动加载：

1. 再次点击顶部状态栏的 ClashX 图标。
2. 找到 **出站规则 (Proxy)** 菜单，在此处选择您想使用的地区节点。
3. 确保 **出站模式 (Mode)** 设置为 **规则 (Rule)**，这样可以保证访问国内网站不绕路，仅在访问海外网站时使用代理。
4. **最关键的一步**：在主菜单中勾选 **设置为系统代理 (Set as System Proxy)**。

此时，小猫咪图标的颜色应该会发生变化（变亮或改变样式），代表代理已经成功接管系统网络。打开浏览器，开始享受畅快的网络世界吧！
