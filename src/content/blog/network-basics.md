## 什么是 TCP 与 UDP？

在数字世界中，数据的传输就像是寄快递。**TCP (Transmission Control Protocol)** 和 **UDP (User Datagram Protocol)** 就是两种不同的“快递公司”。

### 1. TCP：安全可靠的“挂号信”
当你使用 TCP 协议时，发送方和接收方会先建立连接（著名的“三次握手”），确保对方准备好了才开始发数据。
- **优点**：数据绝对不会丢失，如果丢了会自动重传；顺序也不会错乱。
- **缺点**：速度相对较慢，因为确认机制增加了延迟。
- **常见应用场景**：浏览网页 (HTTP/HTTPS)、下载文件、发送邮件。我们平时打开网页，绝大多数流量都是 TCP。

### 2. UDP：追求速度的“平信”
UDP 不管对方在不在，直接把数据包扔过去。
- **优点**：速度极快，没有繁琐的确认握手过程，延迟极低。
- **缺点**：不保证数据一定能送达，可能会丢包。
- **常见应用场景**：在线语音视频通话 (Zoom, 微信视频)、实时多人网络游戏、直播[流媒体](/tag/streaming/)。

## 为什么代理节点需要关心 UDP？

当您在翻墙或者使用代理节点时，大部分传统的网页浏览（TCP）都能完美工作。但是，当您遇到以下情况时，UDP 就显得至关重要了：

1. **打游戏延迟高**：如果您想通过节点玩海外的《绝地求生》或《Apex英雄》，这些游戏几乎全部依赖 UDP 协议来同步玩家位置。如果您的节点**不支持 UDP 转发 (UDP Relay)**，游戏根本连不上或者延迟极高。
2. **语音通话打不通**：使用 Telegram 打语音电话时，如果 UDP 不通，通话质量会非常糟糕。
3. **现代网页协议 (QUIC/HTTP3)**：越来越多的国外大型网站（如 YouTube）开始采用基于 UDP 的 QUIC 协议。如果 UDP 不畅，看 4K 视频可能会卡顿。

### 如何在客户端中开启 UDP？

- **[Clash](/tag/clash/) / [Clash Verge](/blog/clash-verge-vs-clash-for-windows/)**：在设置 (Settings) 或者常规 (General) 面板中，找到 **UDP 转发 (UDP / Allow LAN)** 并开启。
- **[sing-box](/tag/sing-box/)**：在 `outbounds` 节点配置中，确保相关的路由规则允许 UDP 流量通过。

> **⚠️ 站长提示**：并不是所有的机场节点都支持 UDP 转发。部分廉价机场为了节省服务器带宽，会在服务端屏蔽 UDP。如果您是游戏玩家，在购买机场时一定要向客服确认是否支持 **Fullcone UDP** 或完全的 UDP Relay。
