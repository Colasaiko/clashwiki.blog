在 Windows 平台上，曾经最辉煌的客户端是 Clash for Windows (CFW)。但随着 CFW 停止更新，基于全新架构开发的 **Clash Verge (Rev)** 凭借更低的内存占用、更美观的界面以及原生集成 Meta 内核，已经成为目前 Windows 平台上的最优解。

本教程将手把手教您如何在 Windows 环境下安装并配置 Clash Verge。

## 第一步：下载与安装

1. **获取安装包**：
   请前往 Clash Verge Rev 官方的 GitHub Releases 页面，下载最新的 Windows 安装包（通常后缀为 `.exe` 或 `.zip` 解压版）。推荐下载 `x64-setup.exe` 版本。
2. **执行安装**：
   双击下载的安装包，一路点击“下一步 (Next)”即可完成安装。安装过程中如果遇到安全软件弹窗，请选择“允许”，因为涉及到系统网络底层代理设置。

## 第二步：汉化与基础设置

Clash Verge 启动后默认是英文界面，您可以进行如下设置：
- 点击左侧边栏的 **Settings (设置)**。
- 在 **Basic (基础设置)** 板块中，找到 **Language (语言)**，将其切换为 `简体中文`。
- 建议顺手打开 **系统代理 (System Proxy)** 和 **开机自启动 (Auto Start)** 开关，方便日常使用。

## 第三步：导入订阅链接

要让 Clash 运转起来，您需要从您的服务商（机场）处获取一串**订阅链接 (Subscription URL)**。

1. 登录您购买服务的网站，找到“一键订阅”或“复制 Clash 订阅链接”的按钮。
2. 打开 Clash Verge，点击左侧的 **订阅 (Profiles)** 面板。
3. 在顶部的输入框中，**粘贴**您刚才复制的订阅链接。
4. 点击右侧的 **导入 (Import)** 按钮。
5. 导入成功后，列表中会出现一个新的配置块。**右键点击**该配置，选择 **使用 (Select)**，使其背景变为激活状态的高亮色。

## 第四步：选择节点并启动

1. 切换到左侧的 **代理 (Proxies)** 面板。
2. 在顶部的模式中，选择 **规则 (Rule)** 模式。（这是最推荐的模式，能实现国内外流量自动分流，不影响访问国内网站的速度）。
3. 展开下方的节点列表，您可以点击 **延迟测速 (Latency Test)** 按钮测试所有节点的连通性。
4. 挑选一个带有数字延迟的绿色节点，点击选中它。

至此，您电脑的系统级代理已经成功开启！您可以打开浏览器访问各类国际互联网网站，体验极速冲浪。

> **小贴士**：如果遇到某些软件（如部分游戏平台或命令行工具）不走代理的情况，您可以在“设置”中开启 **TUN 模式**，它会接管系统的所有全局网卡流量，实现更底层的全局代理。
