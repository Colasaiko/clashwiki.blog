## 代理软件能保护你所有的隐私吗？

很多人认为，只要打开了 [Clash](/tag/clash/) 或者 [VPN](/tag/vpn/) 软件，自己的网络行踪就绝对安全了，没有人能知道自己在看什么。**这个想法是极其危险的。**

事实上，如果您没有正确配置代理客户端，或者使用了来历不明的劣质节点，您的真实身份和位置随时都在“裸奔”。以下是三种最常见的隐私泄露方式，以及如何防范它们。

### 1. DNS 泄露 (DNS Leaks)

**什么是 DNS？** 
DNS 就像是互联网的“电话簿”。当你在浏览器输入 `youtube.com` 时，你的电脑会去查电话簿，问“YouTube 的 IP 地址是什么？”

**泄露是如何发生的？**
如果您的代理软件没有接管 DNS 请求，您的电脑依然会向国内的运营商（比如中国电信、中国联通）发送这个查询请求。虽然运营商看不到您看了 YouTube 上的哪个具体视频（因为 HTTPS 加密），但他们**确切地知道**你访问了 YouTube。

**如何防范？**
- 使用 Clash 时，确保开启了 **Fake-IP** 模式，或者开启了 **[TUN 模式](/blog/what-is-proxy-rules-and-tun/)（[虚拟网卡](/blog/what-is-proxy-rules-and-tun/)）**，强制所有 DNS 查询通过代理服务器进行。
- 使用本站的 [DNS 泄露测试工具](/tools/dns-leak/)，如果测出的 DNS 服务器全部位于海外，则说明没有泄露。

### 2. WebRTC 泄露

**什么是 WebRTC？**
这是现代浏览器（Chrome, Firefox, Edge）自带的一种实时通信技术，常用于网页语音、视频通话。

**泄露是如何发生的？**
WebRTC 的底层机制允许网页绕过[系统代理](/blog/clash-timeout-troubleshooting/)，直接获取你电脑的**真实本地 IP 和真实公网 IP**。很多国外的[流媒体](/tag/streaming/)（如 Netflix）或高安全级网站，都会通过一段隐藏的 JavaScript 代码偷偷调用 WebRTC，以此发现你在使用代理。

**如何防范？**
- 最直接的方法：在浏览器安装防泄露插件（如 WebRTC Network Limiter）。
- 进阶方法：如果你使用 [Clash Verge](/blog/clash-verge-vs-clash-for-windows/) 或 [sing-box](/tag/sing-box/) 的 TUN 模式，底层流量会被全面接管，通常能大幅降低 WebRTC 泄露的风险。

### 3. 机场服务商的审计 (Audit Rules)

**泄露是如何发生的？**
你所有的流量虽然对国内 ISP 是加密的，但**必然会经过机场[服务商](/category/airports/)的服务器解密出站**。这就意味着，机场老板理论上可以看到你访问了哪些未加密的 HTTP 网站，以及连接了哪些服务器。
更重要的是，大部分国内机场为了自保，会在服务端配置“审计规则”，屏蔽并记录访问非法敏感网站（如政治、诈骗、极端宗教网站）的用户记录。

**如何防范？**
- 不要使用廉价、不知名的小机场。
- 绝不在连接代理时进行国内的高敏感操作（如登录国内银行、实名社交账号），**将国内流量和国外流量严格分开（使用分流规则）**。
- 对于极端隐私需求，请使用加密等级更高的协议自建节点，或者在代理之上嵌套 Tor 洋葱浏览器。
