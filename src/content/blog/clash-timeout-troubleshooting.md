无论是新手还是老手，在使用 [Clash](/tag/clash/) (如 [Clash Verge](/blog/clash-verge-vs-clash-for-windows/) Rev、Clash for Windows) 时，最让人崩溃的画面莫过于：**点击“延迟测试”后，满屏的红色 `[Timeout](/blog/clash-timeout-troubleshooting/)`，网页死活打不开。**

不要着急重装软件，绝大多数 Timeout 问题都源于几个固定的设置失误。请严格按照以下 5 个步骤进行排查，包你药到病除。

---

## 步​​骤 1：检查电脑系统时间 (最常见的杀手)

**现象**：所有 V2Ray (VMess/[VLESS](/blog/vless-reality-explained/)) 节点全部 Timeout，但如果是 SSR 节点却能连上。

**原因**：为了防止流量被重放攻击，现代[代理协议](/tag/proxy-protocols/)（特别是 VMess）对客户端与服务器的时间差有极其严苛的要求。**如果你的电脑系统时间和标准北京时间相差超过 90 秒，节点将直接拒绝连接。**

**解决方案**：
1. 右键点击电脑右下角的时间，选择“调整日期/时间”。
2. 确保“自动设置时间”开关已打开。
3. 点击“立即同步”按钮，强制系统对齐服务器时间。
4. 重启 Clash，重新测试延迟。

---

## 步​​骤 2：检查本地网络与 DNS

**现象**：不仅国外网站打不开，连着国内网站（如百度、淘宝）也打不开了。

**原因**：Clash 的[规则分流](/blog/what-is-proxy-rules-and-tun/)严重依赖 DNS 解析。如果你的电脑无法正常解析域名，或者你被重定向到了某个需要登录的校园网/酒店 Wi-Fi 验证页面，Clash 会直接卡死。

**解决方案**：
1. 暂时完全退出 Clash（不仅是关掉[系统代理](/blog/clash-timeout-troubleshooting/)，而是右键系统托盘彻底退出软件）。
2. 打开浏览器，看看能不能正常打开 `www.baidu.com`。
3. 如果打不开，说明是你本地的宽带/Wi-Fi 断网了，或者路由器的 DNS 挂了。请先解决基础网络问题，再重启 Clash。

---

## 步​​骤 3：强制更新订阅链接 (解决更新失败与 Network Error)

**现象**：昨天还好好的，今天突然全部 Timeout；或者是刚买的套餐，导入后就不能用；又或者点击更新后提示 `Network Error`，配置刷新后节点列表仍然不变。

**原因**：[服务商](/category/airports/)经常会更换服务器 IP 来应对封锁，或者你的套餐流量用光、已经过期。如果你没有定期更新订阅的习惯，旧 IP 失效后就会全部 Timeout。

**全平台手动更新指南**：
不同的 Clash 客户端操作略有不同：
- **Clash Verge Rev (Windows/Mac)**：进入 `Subscriptions`（订阅）页面，找到你的服务商配置，点击右侧的**刷新图标 (Update)**。
- **Clash for Windows**：进入 `Profiles`，点击你的配置文件右侧的刷新按钮。
- **ClashX (Mac)**：点击状态栏图标 -> `配置` -> `托管配置` -> `更新`。
- **Clash for Android (手机端)**：进入 `配置`，点击右上角的三个点，选择 `更新所有配置`，或者点击单个配置旁边的刷新按钮。

**如果遇到更新失败 (Network Error) 怎么办？**
1. **自动更新配置**：强烈建议在软件中设置“自动更新间隔 (Update Interval)”，例如 24 小时更新一次，防患于未然。
2. **检查网络环境**：更新订阅本身需要连接服务器。如果服务商的订阅域名 (Subscription URL) 被墙了，你在直连状态下就会报 `Network Error`。
   - *解法 A*：打开手机使用 4G/5G 网络尝试更新。
   - *解法 B*：登录服务商官网，获取最新的备用订阅链接 (Subscription URL)，在软件中重新建立一个新的配置。
3. **查看后台状态**：登录服务商后台，确认你的账号状态是否为“正常”，流量是否剩余大于 0。如果流量超标，服务商会主动阻断你的连接。

> **进一步阅读**：如果你的不同客户端配置方式存在差异，可以参考 [BestJichang 的 Clash 订阅与更新配置大全](https://bestjichang.com/blog/clash-14/) 获取更多跨平台技巧。

## 步​​骤 4：检查系统代理冲突

**现象**：Clash 显示连上了，延迟测试也是绿色的（比如显示 120ms），但浏览器就是打不开网页，提示 `ERR_PROXY_CONNECTION_FAILED`。

**原因**：你的电脑里装了其他代理软件（比如老旧的 V2rayN、加速器、甚至某些杀毒软件），它们在抢夺系统的网络控制权，导致 Clash 设置系统代理失败。

**解决方案**：
1. 检查并退出所有其他的代理软件和网游加速器（如 UU 加速器）。
2. 在浏览器中安装“SwitchyOmega”等代理插件，并将其设置为“使用系统代理”或彻底禁用它。
3. 进入 Windows 设置 -> 网络和 Internet -> 代理，手动开启并再关闭一次，让 Clash 重新接管。
4. **终极绝招**：如果浏览器依然死活不走代理，请在 Clash 中打开 **[TUN 模式](/blog/what-is-proxy-rules-and-tun/) ([虚拟网卡](/blog/what-is-proxy-rules-and-tun/)模式)**，强制接管所有流量。

---

## 步​​骤 5：尝试开启全局模式或切换节点

**现象**：YouTube 等大网站打不开，但某些小众国外网站可以打开；或者只有个别节点是红色的。

**原因**：可能是你使用的路由规则（Rule）过期了，导致该走代理的网站没走代理；或者是该节点已经被防火墙精准封锁。

**解决方案**：
1. 在 Clash 的主界面（Proxies），将代理模式从“规则 (Rule)”临时切换为**“全局 (Global)”**。
2. 选定一个节点，刷新网页测试。如果全局模式能打开，说明是你的**分流规则有问题**，请尝试更新 GeoIP/GeoSite 数据库。
3. 挨个点击测试不同的节点。不要执着于某一个节点，跨境网络波动是常态，东边不亮西边亮。

> [!CAUTION]
> 如果你试遍了以上 5 个步骤，依然满屏 Timeout，那么 99% 的概率是：**你的服务商跑路了，或者遭到了严重的 DDOS 攻击拔了网线。** 此时请前往服务商的 Telegram 官方群组查看最新公告，或者考虑更换一家稳定的备用服务商。
