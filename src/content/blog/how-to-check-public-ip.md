在当今复杂的互联网环境中，了解自己当前的网络出口状态是每一位极客和注重隐私的用户的必备技能。无论是排查家庭宽带问题，还是验证代理节点是否真正生效，第一步往往都是：**查询自己的公网 IP**。

很多新手可能会疑惑：“我在电脑上查到的 `192.168.x.x` 难道不是我的 IP 吗？” 

这篇文章将为您彻底扫盲关于 IP 地址的核心概念，并教您如何精准检测自己当前的网络出口信息。

---

## 一、 为什么查出来的 IP 和电脑上显示的不一样？

在绝大多数家庭和企业网络中，设备处于路由器分配的**局域网（LAN）**内部。您在电脑或手机的网络设置里看到的诸如 `192.168.1.10` 或 `10.0.0.5`，都属于**私有 IP 地址（Private IP）**。

这些私有 IP 只能在您的局域网内互相通信。当您的数据需要访问国际互联网时，路由器会通过 NAT（网络地址转换）技术，将这些私有 IP 统一伪装成运营商分配给您的**公网 IP（Public IP）**发出去。

也就是说：**外部网站（如 Google, [Clash](/tag/clash/)Wiki）看到的，永远是您的公网 IP。**

---

## 二、 IP 信息包含哪些核心数据？

一个完整的 IP 查询结果，绝不仅限于一串数字。通过查询专业的 IP 数据库（如 IPinfo, MaxMind），我们可以解析出该 IP 背后的丰富身份档案：

### 1. IP 协议版本 (IPv4 vs IPv6)
- **IPv4**：传统的 IP 格式（如 `114.114.114.114`），目前资源已极度枯竭，通常需要和整个小区的用户共享一个公网 IPv4。
- **IPv6**：新一代 IP 格式（如 `240e:3b6:...`），地址数量近乎无限。目前三大运营商的手机流量和宽带均已全面普及 IPv6。

### 2. 地理位置 (Country / City / Timezone)
IP 数据库会记录该 IP 段被分配到了哪个国家、哪个城市。
> **注意**：这里的地理位置是**注册地**或**机房所在地**，并不代表使用者的真实物理坐标。很多代理节点会通过“广播 IP”将美国机房的 IP 强行标记为新加坡，这就是俗称的“假落地”。

### 3. 网络服务商 (ISP)
即提供该 IP 接入服务的公司。例如，在中国大陆通常是 `China Telecom`（公开资料汇总）、`China Unicom`（公开资料汇总）；而在海外服务器上，可能是 `Amazon.com` (AWS)、`DigitalOcean` 等云[服务商](/category/airports/)。

### 4. 自治系统编号 (ASN)
**这是高阶网络诊断中最重要的一环。**
ASN (Autonomous System Number) 是全球网络路由的身份证。每一个大型网络服务商或云厂商都有一个全球唯一的 ASN。例如：
- 看到 `AS4134`，就知道这是公开资料汇总的 163 骨干网。
- 看到 `AS13335`，就知道这是 Cloudflare 的 CDN 节点。
通过 ASN，我们可以精准判断一个 IP 到底是纯正的“家庭宽带原生 IP”，还是被万人骑的“数据中心机房 IP”。
