由于安卓系统极高的开放性，在 Android 设备上运行代理工具不仅稳定，还能实现极其精细的应用级别分流（例如只让 Telegram 走代理，微信走直连）。

目前安卓端最著名的两大客户端是 **Clash for Android (CFA)** 和 **Surfboard**。

## 选择您的客户端

1. **Clash for Android (CFA)**：历史最悠久、知名度最高。界面略显极客风，完美支持绝大多数机场的一键导入。
2. **Surfboard (冲浪板)**：后起之秀，UI 更加精致现代，耗电控制表现极其优秀，并且同样兼容大部分 Surge/Clash 的订阅节点。

*本文以受众最广的 Clash for Android (小猫咪) 为例进行演示。*

## 步骤一：安装客户端

由于国内安卓应用商店（如华为、小米、OV商店）无法搜到此类应用，您需要通过 APK 安装包直接安装：
1. 访问项目官方 GitHub 的 Releases 页面下载最新版 `.apk` 文件。大部分现代手机下载 `universal` 或 `arm64-v8a` 版本均可。
2. 下载后点击安装，如果系统提示“未知来源应用警告”，请选择“允许安装”。

## 步骤二：一键导入订阅

对于手机用户，最方便的方式就是“一键导入”：

1. 使用手机浏览器登录您的服务商（机场）后台面板。
2. 找到“一键订阅”或“导入到 Clash”的快捷按钮，点击它。
3. 此时系统会自动唤醒您刚安装好的 Clash for Android 客户端，并弹出一个配置下载窗口。
4. 核对无误后点击右上角的**保存**图标（软盘图标），等待几秒钟下载完成。
5. 下载完成后，点击刚刚新增的配置卡片，使其左侧出现一个**绿色圆圈**，代表已激活。

*(如果是手动复制了订阅链接，可以点击 CFA 首页的“配置” -> 右上角“+”号 -> “从 URL 下载”，粘贴链接保存即可。)*

## 步骤三：开启代理服务

1. 返回应用最顶部的**主页**。
2. 点击页面中央最醒目的 **“点此启动” (Tap to start)** 按钮。
3. 首次启动时，安卓系统会弹出一个极度核心的警告提示：“Clash 正在请求建立一个 VPN 连接...”
4. 这是安卓系统的标准安全机制，必须点击 **允许 / 确定**。（不用担心，这只是建立本地代理隧道的必要权限）。
5. 启动成功后，点击下方的 **“代理” (Proxies)** 面板，选择 `规则 (Rule)` 模式，并挑选一个低延迟节点。

## 耗电与后台优化建议

部分安卓手机（尤其是国内定制 ROM，如 MIUI、ColorOS、OriginOS）杀后台极其严重。为了防止您正在愉快看剧时代理软件突然掉线，请务必进行以下设置：
- 打开多任务后台视图，将 Clash 应用**加锁 (向下划或点击锁形图标)**。
- 进入手机的系统设置 -> 电池/应用管理 -> 找到 Clash -> 将耗电策略设置为**无限制**或**允许完全后台运行**。
