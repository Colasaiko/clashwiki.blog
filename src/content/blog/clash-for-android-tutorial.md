由于安卓系统极高的开放性，在 Android 设备上运行代理工具不仅稳定，还能实现极其精细的应用级别分流（例如只让 Telegram 走代理，微信走直连）。

目前安卓端最著名的两大客户端是 **Clash for Android (CFA)** 和 **Surfboard**。本文将以受众最广的 Clash for Android (俗称“小猫咪”) 为例，带您完成从零到一的配置指南。

## 1. 你需要准备什么

在正式开始之前，请确保具备以下条件：
- 一部运行 Android 7.0 及以上系统的智能手机。
- **一个有效的机场订阅链接**（如果您还没有，请前往 [品牌库](/brands/) 挑选一个适合您的服务商）。

## 2. 下载

由于国内安卓应用商店（如华为、小米、OV商店）无法搜到此类应用，您需要通过 APK 安装包直接下载：
1. 访问 Clash for Android 官方 GitHub Releases 页面，获取最新版 `.apk` 文件。
2. 大部分现代手机选择 `universal` 或 `arm64-v8a` 版本下载即可。

## 3. 安装

1. 在手机的文件管理器或浏览器下载中心找到刚才下载的 `.apk` 文件。
2. 点击安装。如果系统弹出“未知来源应用警告”或“拦截未知应用”，请进入设置选择“允许安装”。
3. 安装完成后，您会在桌面上看到一只灰色的“小猫咪”图标。

## 4. 启动

1. 点击桌面图标启动 Clash for Android。
2. 首次启动通常没有多余的弹窗，您会直接看到干净的主界面。建议此时不要做任何设置，先完成下一步的配置导入。

## 5. 导入配置

对于手机用户，最方便的方式就是“一键导入”：

1. 使用手机浏览器登录您的服务商（机场）后台面板。
2. 找到“一键订阅”或“导入到 Clash”的快捷按钮，点击它。
3. 此时系统会自动唤醒 Clash for Android 客户端，并弹出一个配置下载窗口。
4. 核对无误后点击右上角的**保存**图标（软盘图标），等待几秒钟下载完成。
5. 下载完成后，点击刚刚新增的配置卡片，使其左侧出现一个**绿色圆圈**，代表该配置已激活。

*(注：如果一键导入失败，您可以手动复制订阅链接，点击 CFA 首页的“配置” -> 右上角“+”号 -> “从 URL 下载”，粘贴链接并保存即可。)*

## 6. 选择节点

配置激活后，我们需要挑选一条快速的线路：
1. 返回应用主页，点击页面下方的 **“代理” (Proxies)** 面板。
2. 在顶部的分流模式中，选择 **规则 (Rule)** 模式。
3. 点击右下角的闪电图标进行一次批量公开数据评估。
4. 从列表中挑选一个带有绿色数字（即延迟较低）的节点点击选中。

## 7. 开启系统代理

1. 返回应用最顶部的**主页**。
2. 点击页面中央最醒目的 **“点此启动” (Tap to start)** 按钮。
3. **关键步骤**：首次启动时，安卓系统会弹出一个核心的警告提示：“Clash 正在请求建立一个 VPN 连接...”
4. 这是安卓系统的标准安全机制，必须点击 **允许 / 确定**。（这只是建立本地代理隧道的必要权限）。
5. 启动成功后，顶部状态栏通常会出现一把小钥匙（或 VPN 字样）图标。

## 8. 测试

一切就绪！现在您可以打开浏览器或 YouTube 客户端。如果视频和页面能够正常加载，恭喜您，手机端配置已全部完成。

## 9. 常见错误

- **频繁掉线 / 在后台被自动清理**：国内安卓手机（如 MIUI、ColorOS）杀后台极其严重。请打开多任务视图将 Clash 应用**加锁**，并在手机“设置 -> 电池”中将其耗电策略改为**无限制**或**允许完全后台运行**。
- **无法连接网络**：如果您能看国内网站但打不开国国际互联网服务站，可能是刚才选的节点失效了，请回到“代理”面板重新公开数据评估并更换节点。
