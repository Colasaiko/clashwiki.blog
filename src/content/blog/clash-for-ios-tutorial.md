在 iOS (iPhone / iPad) 平台上，您在 App Store 里是**搜索不到官方名为 Clash 的应用程序的**。但不用担心，iOS 生态拥有极为丰富且强大的代理工具替代方案，它们不仅能完美解析 Clash 订阅链接，甚至在交互体验上做得更好。

目前最主流的三大神器分别是：**Shadowrocket (小火箭)**、**Quantumult X (圈X)** 以及主打无缝兼容 Clash 的 **Stash**。

## 为什么我搜不到这些 App？

由于中国大陆区 App Store 的政策限制，所有提供代理功能的网络工具（VPN类应用）均无法上架。
**解决方法**：您必须准备一个**非中国大陆地区（如美区、日区、港区）的 Apple ID**。
- 您可以自己注册一个外区账号（教程网上一搜一大把）。
- 您也可以通过第三方平台购买已注册好的空账号或兑换码。
- *部分优质服务商甚至会向付费用户提供免费的公共外区 Apple ID 以供下载。*

## 推荐客户端一览

1. **Shadowrocket（小火箭）**：
   iOS 上知名度最高、使用人数最多的客户端，售价约为 $2.99。操作最傻瓜式，支持几乎所有已知协议，极其适合新手。
2. **Stash**：
   被称为“iOS 上的 Clash”。如果您在电脑端已经习惯了 Clash，或者使用的是高度定制化的 Clash 规则，Stash 是最完美的无缝衔接方案，售价约 $3.99。
3. **Quantumult X (圈X)**：
   界面极具赛博朋克感，拥有极高的自定义权限，适合喜欢折腾脚本、去广告功能的高级玩家，售价约 $7.99。

## 基础配置教程：以 Shadowrocket 为例

由于其超高的普及率，这里以 Shadowrocket 为例进行说明。

### 1. 下载与安装
打开手机的 App Store，点击右上角头像，滑到最底部退出当前的大陆账号，登录您的外区 Apple ID。搜索 `Shadowrocket`（认准那个蓝色火箭图标），购买并下载安装。

### 2. 导入订阅节点
1. 打开手机 Safari 浏览器，登录您的服务商网站。
2. 找到快捷订阅按钮，点击 **“一键导入到 Shadowrocket”**。
3. 手机会自动跳转打开小火箭，并且会提示成功添加节点配置。
4. 您也可以手动复制“订阅链接”后，打开小火箭，点击右上角的 **“+” 号**，类型选择 **Subscribe (订阅)**，在 URL 栏粘贴链接并保存。

### 3. 连接与测试
1. 在主界面的列表中，点击选中一个延迟较低的节点（左侧出现橙色小圆点代表已选中）。
2. 将最顶部的 **未连接 (Not Connected)** 右侧开关打开。
3. 首次开启时，iOS 会弹窗提示 `“Shadowrocket” Would Like to Add VPN Configurations`。
4. 点击 **Allow (允许)**，并输入手机锁屏密码或使用 Face ID 进行授权。
5. 成功后，手机屏幕最顶部的时间旁边会出现一个 `VPN` 或 `🔒` 的小图标。

此时，您就已经成功接入代理网络了。在最底部的 **配置 (Config)** 页面，确认**全局路由**选择为 **配置 (Config)**，即可实现智能国内外分流。
