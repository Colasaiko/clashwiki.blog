许多人在第一次使用 [ChatGPT](/tag/chatgpt/) 时，常常会觉得“它很笨”，或者“写出来的东西太像机器了”。

其实，AI 的能力上限往往取决于使用者的提问水平。在 AI 圈子里，写出高质量的问题被称为 **Prompt Engineering（提示词工程）**。掌握了这门技术，你能让 AI 输出的质量提升十倍以上。

本文将为您介绍几个写出高质量 Prompt 的核心框架和技巧。

---

## 1. 告别短句，提供充分的“背景信息”

**❌ 错误的提问**：
> 帮我写一篇关于 iPhone 16 的测评文章。

这种提问得到的回复，必然是一篇平庸、空洞的百度百科式文章，因为 AI 不知道你的受众是谁，也不知道你想强调什么。

**✅ 正确的提问**：
> **[背景]** 我是一个专注做数码硬件评测的自媒体博主，我的粉丝主要是喜欢玩原神、看重手机性能和性价比的男大学生。
> **[任务]** 帮我写一篇关于 iPhone 16 的评测脚本。
> **[核心要求]** 重点突出 A18 芯片在玩游戏时的发热情况，并对比前代 iPhone 15。语气要幽默、接地气。

**核心原理**：AI 需要“锚点”。你给的背景信息越多，它调用的模型权重就越精准。

## 2. 赋予 AI 一个“角色” (Role-Playing)

让大模型进入特定角色的状态，能显著提升其输出的专业度。

**💡 框架示例**：
> 从现在起，你是一位拥有 20 年经验的资深心理咨询师。
> 你的语言风格是：温和、包容、擅长使用苏格拉底式提问引导患者思考，而不是直接给出大道理。
> 现在，我的问题是：最近工作压力极大，每天晚上都失眠，我该怎么办？

**核心原理**：大模型在训练时阅读了海量的文本。当你指定“资深心理医生”时，它会立刻激活那些与心理学、专业咨询相关的神经元网络，从而屏蔽掉网上那些不靠谱的键盘侠言论。

## 3. 使用“结构化提示词”框架

在长文本或复杂任务中，如果你把所有要求糅杂在一起，AI 很容易“漏听”指令。这时候需要像写代码一样，使用 Markdown 符号将指令**结构化**。

目前最流行的是 **BROKE 框架**：
- **B (Background)**：背景
- **R (Role)**：角色
- **O (Objective)**：目标
- **K (Key Results)**：关键结果
- **E (Evolve)**：迭代

**💡 结构化 Prompt 模板**：
```markdown
# Role
你是一名资深的海外社媒运营专家。

# Background
我的公司刚推出一款智能猫砂盆，现在准备通过小红书和 TikTok 进行海外推广。

# Objective
帮我制定一个为期 14 天的冷启动内容运营计划。

# Key Results
- 必须包含：每天的发帖主题。
- 必须包含：建议使用的 3 个热门 Hashtag。
- 必须包含：对应的短视频脚本大纲（每个不超过 100 字）。
- 输出格式：请使用清晰的 Markdown 表格呈现。

# Constraints
- 避免使用营销味道过重的套话。
- 内容必须迎合 20-35 岁热爱宠物的年轻女性受众。
```

## 4. 给出“示例” (Few-Shot Prompting)

如果你希望 AI 模仿某种特定的文风、或者按照特定格式输出数据，**直接给它看一个例子，比解释一万句规则都管用**。

**💡 示例**：
> 请帮我提取以下文本中的公司名称、成立时间和融资金额，并转换为 JSON 格式。
> 
> **示例输入**：字节跳动成立于 2012 年，并在近期完成了 20 亿美元的融资。
> **示例输出**：{"company": "字节跳动", "founded": "2012", "funding": "20亿美元"}
> 
> **正式任务**：Anthropic 成立于 2021 年，刚宣布获得了亚马逊 40 亿美元的战略投资。

## 结语

写 Prompt 就像是在指挥一个绝顶聪明、但没有任何社会常识的实习生。
不要指望它能“心领神会”，把目标拆碎、把规则定死、把背景交待清楚，你就能收获一个拥有超级大脑的生产力引擎。
