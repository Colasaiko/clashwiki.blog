在 AI 浪潮下，编程的门槛正在被史无前例地拉低。如果你是一个从来没写过一行代码的小白，或者是一个每天被繁杂业务代码折磨的程序员，**Cursor** 将是你在这个时代最值得掌握的工具，没有之一。

Cursor 是一款基于 VS Code 深度定制的 AI 代码编辑器。它不是简单的“在代码里加上一个对话框”，而是将 AI 深度融入了你敲击键盘的每一次操作。

---

## 1. 为什么是 Cursor？

过去，我们用 ChatGPT 辅助编程的流程是：
1. 复制报错信息。
2. 切出浏览器，粘贴给 ChatGPT。
3. 等待回复，复制 AI 写的代码。
4. 切回代码编辑器，寻找合适的位置粘贴。

而在 Cursor 中，AI 直接“住”在了你的代码库里。
它能**阅读你的整个项目文件**，了解你定义的所有变量和函数；当你遇到报错时，只需一键点击 `Debug with AI`，它就能直接在原代码位置生成修复方案（Diff），你只需要点击 `Accept` (接受) 即可。

## 2. Cursor 核心功能扫盲

### Cmd + K：行内代码生成
这是 Cursor 最常用的快捷键。在代码的任意位置按下 `Cmd + K` (Windows 为 `Ctrl + K`)，会弹出一个输入框。
你可以直接输入自然语言指令，例如：
*“写一个使用 fetch 请求当地天气接口的异步函数，并处理错误。”*
Cursor 会在光标处立刻生成这段代码。

### Cmd + L：懂你全栈的侧边栏助理
按下 `Cmd + L` 会呼出右侧的 AI 对话面板。
它的强大之处在于**上下文能力**。你可以使用 `@` 符号引入各种资源：
- `@Files`：让 AI 仔细阅读你指定的某个文件。
- `@Codebase`：让 AI 扫描你的整个项目（比如：*“@Codebase 我们目前是怎么处理用户登录状态的？”*）。
- `@Web`：让 AI 去网上搜索最新的官方文档，防止因为 AI 知识库太旧而生成过时的代码。

### Cursor Tab：拥有读心术的自动补全
比起传统 IDE 的变量补全，Cursor 的 Tab 补全是基于上下文预测的。
有时候你刚写完一行代码，换行后，Cursor 已经用灰色字体预测出了你接下来整整一个代码块的逻辑。如果你觉得没问题，直接按下 `Tab` 键即可全部采纳。

## 3. 小白如何开始第一个 AI 项目？

1. **下载安装**：前往 Cursor 官网免费下载安装包。因为它底层就是 VS Code，你可以一键导入之前 VS Code 里的所有插件和主题。
2. **选择模型**：在设置中，将模型切换为目前代码能力最强的 **Claude 3.5 Sonnet**。
3. **建立对话**：打开一个空白文件夹，按下 `Cmd + L`，输入：“我是一个没有任何编程基础的小白，我想写一个简单的贪吃蛇网页小游戏。请一步一步指导我，告诉我应该创建什么文件，以及里面写什么代码。”
4. **一键应用**：当 AI 给出代码后，你可以点击代码块右上角的 `Apply` 按钮，Cursor 会自动帮你把代码填入对应的文件中。
