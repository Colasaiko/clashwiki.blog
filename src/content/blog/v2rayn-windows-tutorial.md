v2rayN 是一款在 Windows 平台上历史悠久、功能强大的网络代理客户端，支持 Vmess, Vless, Shadowsocks, Trojan 等多种协议。

## 安装步骤

1. 前往 GitHub 下载最新的 v2rayN 压缩包。
2. 解压到非中文路径。
3. 如果系统提示缺少 .NET Framework，请根据提示前往微软官网下载安装。
